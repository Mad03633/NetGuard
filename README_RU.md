# NetGuard — когнитивная система поддержки решений

Интерфейс Streamlit и презентация переведены на русский язык. Система помогает аналитику выбрать реакцию на сетевой инцидент: **наблюдение**, **проверку аналитиком** или **предложение карантина**.

## Запуск

В подготовленной локальной копии запустите `RUN_WINDOWS.cmd` и откройте `http://localhost:8501`.

На другом компьютере установите Python **3.10–3.12**, распакуйте ZIP и выполните в папке проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run streamlit_app.py --server.address 127.0.0.1
```

## Работа с приложением

1. В «Данных и приоритетах» выберите демонстрационный сценарий, загрузите CSV/TXT или выберите запись NSL-KDD.
2. Просмотрите семь вкладок: **Восприятие → Внимание → Память → Рассуждение → Решение / СППР → Действие → Обучение**.
3. Настройте веса: **Защита** — выгода, **Нарушение работы** и **Трудозатраты** — затраты. Значения критериев можно редактировать в блоке допущений. СППР использует метод взвешенной суммы WSM и показывает вклады критериев.
4. Во вкладке «Решение / СППР» измените независимые веса «Что, если…» и сравните ранжирование с исходным.
5. Во вкладке «Действие» выберите итоговый вариант и подтвердите сохранение локального отчёта. Реального карантина и изменения настроек сети нет.
6. В «Обучении» укажите подтверждённый исход отчёта. Это обновит память и повлияет на последующие оценки. Одну и ту же обратную связь нельзя применить дважды.

Кнопка «Запустить отдельную демонстрацию обучения» показывает изменение риска с **0,6542 до 0,3373** и смену рекомендации с предложения карантина на проверку аналитиком. Опыт использует временную базу и не изменяет вашу память.

## Совместимость

Русские названия используются в интерфейсе. Поля CSV, внутренние коды вариантов и схема JSON/SQLite сохранены, поэтому существующие файлы и память продолжают работать. Для загрузки CSV используйте технические заголовки из скачиваемого шаблона.

Системные панели стандартных компонентов Streamlit и отдельное исходное браузерное демо могут содержать английские элементы. Исходные материалы NetGuard сохранены; русская СППР открывается на порту 8501.
